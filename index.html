GUIDE

사용 방법 · 자주 묻는 질문

위도·경도와 주소를 서로 변환하는 방법과 변환 기준을 정리했습니다.

위도·경도로 주소를 찾으려면 어떻게 하나요?

'GPS 좌표 → 주소' 칸에 위도와 경도를 입력하고 변환 버튼을 누르면 해당 위치의 지번 주소가 표시되고 지도에 위치가 나타납니다.

주소로 위도·경도 좌표를 찾을 수 있나요?

네. '주소 → GPS 좌표' 칸에 도로명 주소나 지번 주소를 입력하고 변환 버튼을 누르면 위도·경도(WGS84)가 표시됩니다.

도분초(DMS) 형식 좌표도 입력할 수 있나요?

네. 37°33'59.4"N, 126°58'40.8"E처럼 도분초로 입력하면 십진수(37.5665, 126.978)로 자동 변환한 뒤 주소를 찾습니다.

변환 결과는 어떤 데이터를 기준으로 하나요?

국토교통부 브이월드(VWorld) 오픈 API의 주소·좌표 변환 결과를 사용하며, 좌표는 WGS84(EPSG:4326) 위도·경도 기준입니다. 대한민국 안의 주소와 좌표만 변환할 수 있습니다.

내 현재 위치의 위도·경도를 확인할 수 있나요?

'시스템에서 현재 위치 정보 읽기' 버튼을 누르고 브라우저의 위치 권한을 허용하면 현재 위치의 위도·경도와 주소가 자동으로 입력됩니다.

찾은 위치를 다른 사람에게 공유할 수 있나요?

변환이 끝나면 위치 QR 코드와 단축 주소가 만들어집니다. QR 코드를 스캔하거나 단축 주소로 접속하면 같은 위치가 지도에 표시됩니다.

변환 기준

좌표계WGS84 (EPSG:4326) 위도·경도
입력 가능한 좌표 형식십진수 (예: 37.5665), 도분초 (예: 37°33'59.4"N)
주소 → 좌표 입력도로명 주소 또는 지번 주소
좌표 → 주소 결과지번 주소
좌표 소수 자리입력한 좌표·지도에서 고른 위치·현재 위치는 소수점 6자리로 반올림 (위도 방향 약 0.11m)
데이터 출처국토교통부 브이월드(VWorld) 오픈 API
지원 지역대한민국

좌표 가이드

  • 도분초(DMS) 좌표를 십진수로 바꾸는 방법
  • 위도·경도 소수점 자리수별 정밀도
  • 내 현재 위치의 위도·경도 확인하는 방법
