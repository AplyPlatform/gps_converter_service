내 현재 위치의 위도·경도 확인하는 방법

gps.aply.biz에서 '시스템에서 현재 위치 정보 읽기' 버튼을 누르고 위치 권한을 허용하면 현재 위치의 위도·경도와 주소가 자동으로 표시됩니다.

확인하는 순서

  1. gps.aply.biz에 접속합니다.
  2. '시스템에서 현재 위치 정보 읽기' 버튼을 누릅니다.
  3. 브라우저가 위치 정보 사용을 물으면 허용을 누릅니다.
  4. 위도·경도 칸이 채워지고, 주소와 지도 위치가 함께 표시됩니다.

위치를 읽지 못하거나 정확하지 않을 때

증상원인해결 방법
위치 권한 거부 안내가 나옴브라우저나 휴대폰 설정에서 위치 권한이 꺼져 있음브라우저 주소창의 사이트 설정에서 위치 권한을 '허용'으로 바꾼 뒤 다시 시도
좌표가 실제 위치와 많이 다름실내이거나, PC처럼 GPS 수신기가 없어 Wi-Fi 등 네트워크 정보로 위치를 추정함휴대폰의 위치(GPS)를 켜고 실외에서 다시 시도
버튼을 눌러도 동작하지 않음위치 정보는 보안 연결(https)에서만 사용할 수 있음https://gps.aply.biz 주소로 접속했는지 확인
시간 초과 안내가 나옴위성·네트워크 신호를 제때 받지 못함잠시 후 다시 시도하거나 신호가 좋은 곳으로 이동

좌표의 소수점 자리수가 실제 몇 m인지는 위도·경도 소수점 자리수별 정밀도에서 확인할 수 있습니다.
